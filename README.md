# Demo — Portal para Despacho Contable

Demostración (datos de ejemplo) de un portal para un despacho contable:
tablero, facturación CFDI, cálculo de IVA/ISR, estados financieros,
clientes y obligaciones ante el SAT.

**Correr:** `py -m streamlit run app.py` — entra con usuario/clave `demo`.

Todos los datos son inventados; es solo para demostración.
